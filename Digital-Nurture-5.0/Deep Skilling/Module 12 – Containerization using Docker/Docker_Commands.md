# Docker Commands

## Check Docker Version

docker --version

---

## List Images

docker images

---

## Run Container

docker run hello-world

---

## List Running Containers

docker ps

---

## Stop Container

docker stop <container-id>

---

## Remove Container

docker rm <container-id>

---

## Pull Image

docker pull nginx

---

## Execute Command

docker exec -it <container-id> bash
