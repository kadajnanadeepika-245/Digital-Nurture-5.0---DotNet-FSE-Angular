# Module 12 – Containerization using Docker

## Overview

This project demonstrates Docker fundamentals, Docker commands, Docker images, Docker Compose, Docker networking, Docker storage, Docker Engine, and Container Orchestration.

- Understand Docker

- Learn Docker Engine
- Learn Docker Storage
- Learn Docker Networking
- Learn Container Orchestration
