# Difference between CI and CD

| Continuous Integration | Continuous Delivery |
|------------------------|--------------------|
| Automatically builds code | Automatically prepares deployment |
| Frequent code integration | Frequent releases |
| Detects bugs early | Faster delivery |
| Executes automated tests | Deploys application |
